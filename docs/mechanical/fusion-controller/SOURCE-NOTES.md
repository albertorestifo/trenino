# Native model and source notes

Open Fusion-Train-Controller.f3d in Autodesk Fusion. The live cloud document was saved as AIDesignedLever v5. The geometry is native sketch/extrude/revolve feature history, with396 healthy features and separately named components. Grounded exact-frame mesh reference is not a printed part.

The supplied Python scripts document construction and checks through the installed Fusion MCP. They use absolute paths from the development workspace; adjust ROOTDIR and exec(open(...)) paths before regeneration. They are not intended to be rerun on the completed document. Regeneration starts from a new empty Hybrid Design and uses this order:01,02,03,04,05,06,07,09,10,11,13,14,19,20,22,17,24,26,27. Scripts08,12,15,21,23 inspect geometry;16,18,25 export/capture. common.py supplies geometry helpers. The source contains deliberate incremental corrections; the final native archive is the easiest editable starting point.

Print the oriented STL files in the order in ASSEMBLY-AND-PRINT-GUIDE.md.29 files include3 cam alternatives and2 coupling-disc fits; select one of each. Do not print the entire assembly or metal frame. No generated printer G-code is included.

Mount-access revision: scripts26/27 modify the mounts and M3 hardware. Scripts28/29 check insertion, driver access, sampled motion and neutral fit. Do not rerun mutation scripts on the completed model. The separate changed-parts Bambu project is documented in CHANGED-PARTS-PRINT.md.

Support-reduction revision, 2026-10-25: append scripts30 and32 to the regeneration order above. Script30 adds the P17 flange ramp and cuts the grip socket roof slopes; script32 relieves the ramp around the clamp washer. Script31 checks changed-part clearances at53 poses. orient_meshes.py now stands P09/P10 upright and P19/P20 on their axial ends. Geometry changes affect only P09/P10/P17; P18 is a slicing change and P19/P20 are orientation changes. The separate support-revision folder contains the locally prepared Bambu project and sliced archive, previews and evidence. build_support_review_project.py creates a preliminary project; the final project is subsequently saved through Bambu Studio.
